# ShakeMeal 🍜

> Shake your device for a nearby meal. AI powered — best choice for people with decision paralysis.

---

## System Architecture

```
iOS App (SwiftUI)
  CoreLocation · CoreMotion · StoreKit 2 · APNs
        │
        │  HTTPS / REST + JWT
        ▼
Go API Server  ── hosted on Railway / Fly.io
  (SSL, load balancing, reverse proxy handled by platform)
        │
   ┌────┤
   ▼    ▼
Postgres    Google Places API
(users,     (restaurant data)
 favs,
 history,
 places cache)
        │
        ▼
Apple App Store API
(subscription verification)
        │
        ▼
Sentry + PostHog
(crash reporting + analytics)
```

---

## Tech Stack

| Layer              | Choice                            | Notes                                     |
|--------------------|-----------------------------------|-------------------------------------------|
| **iOS**            | SwiftUI                           | Native, modern, great animations          |
| **Shake / Motion** | CoreMotion                        | Built-in shake detection                  |
| **Location**       | CoreLocation                      | Native GPS                                |
| **Payments**       | StoreKit 2                        | In-app purchases & subscriptions          |
| **Push**           | APNs (direct)                     | iOS-only, no extra dependency             |
| **Backend**        | Go + Gin                          | Fast, lightweight, cheap to host          |
| **Database**       | PostgreSQL                        | Users, favorites, history, preferences    |
| **Cache**          | PostgreSQL                        | Places cache table, add Redis when needed |
| **Places Data**    | Google Places API                 | Best global coverage, cached to save $$   |
| **Auth**           | Anonymous → Sign in with Apple + JWT | Zero-friction onboarding               |
| **Hosting**        | Railway / Fly.io                  | Handles SSL, reverse proxy, load balancing|
| **Errors**         | Sentry                            | iOS + Go in one place                     |
| **Analytics**      | PostHog                           | Funnels, retention, open-source           |

## API Overview

```
# Auth
POST   /api/v1/auth/apple          Sign in with Apple
POST   /api/v1/auth/refresh        Refresh JWT

# Core
GET    /api/v1/shake               Random nearby restaurant
         ?lat=&lng=&radius=&cuisine=&price=&exclude=

# Favorites
GET    /api/v1/favorites
POST   /api/v1/favorites
DELETE /api/v1/favorites/:place_id

# History
GET    /api/v1/history
POST   /api/v1/history             Record a visit ("Let's Go!" tapped)
DELETE /api/v1/history

# Preferences
GET    /api/v1/preferences
PUT    /api/v1/preferences

# Webhooks
POST   /api/v1/webhooks/apple/iap  Apple subscription events

# Health
GET    /health
```

## Database Schema

```
users            → id, apple_id, email, is_pro, device_id, deleted_at
user_preferences → user_id, default_radius, cuisines[], price_levels[]
favorites        → id, user_id, place_id, name, address, lat, lng, rating
shake_history    → id, user_id, place_id, name, address, lat, lng, shook_at
places_cache     → place_id, data (jsonb), lat, lng, cached_at
```

## Getting Started

### iOS

```bash
# Install XcodeGen (one-time)
brew install xcodegen

# Generate Xcode project and open
cd ios
xcodegen generate
open ShakeMeal.xcodeproj
```

> The app runs immediately with mock data.
> Shake the simulator via **Device → Shake**, keyboard shortcut `Cmd+Ctrl+Z`, or tap **Shake Now**.
> Before submitting to the App Store, add your Apple Team ID to `ios/project.yml`.

### Backend

```bash
cd backend
cp .env.example .env          # set GOOGLE_PLACES_API_KEY (optional — mock is used if missing)

# Run with local Postgres
make docker-db                # starts Postgres only
make migrate                  # run SQL migrations (requires: brew install golang-migrate)
make run                      # starts API at localhost:8080

# Or run everything in Docker
make docker-up

# Smoke test
curl http://localhost:8080/health
curl "http://localhost:8080/api/v1/shake?lat=37.7749&lng=-122.4194"
```
